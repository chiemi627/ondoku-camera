# おんどくカメラ

英語のプリントをスマホのカメラで撮ると、印刷された英文だけを抜き出して読み上げる Web アプリ。
公文の英語プリントの音読練習用に作ったもの。

## つかいかた

1. 「プリントを撮る」でプリントを撮影する（撮影済みの写真からも選べる）
2. 英文が1行ずつ抜き出される
3. 「ぜんぶ読む」で上から順に読み上げ。英文をタップすると、その行だけをくりかえす
4. 読みまちがいがあれば「なおす」で文字を直したり、いらない行を消せる

はやさ（0.5〜1.2倍）、くりかえし回数（1〜3回）、英語の声は下のバーで変えられる。
設定と、読んだプリントの記録（直近10件）は端末の中に保存される。

## しくみ

- **文字の読み取り**：[Tesseract.js](https://github.com/naptha/tesseract.js) v7。端末の中だけで動く。サーバーには何も送らない
- **読み上げ**：ブラウザの Web Speech API（端末内蔵の音声）
- **前処理**：撮影画像を長辺 1500〜2400px に調整し、グレースケール化とコントラスト伸張をかけてから認識させる
- **後処理**：信頼度の低い行、記号だらけの行、教材番号（`E 21a` など）を捨て、折り返された文をつなぎ、1行に複数の文があれば分ける

初回だけ OCR エンジンと英語の辞書データ（約4MB）を読み込む。
Service Worker がそれらを保存するので、2回目からはオフラインでも動く。

## 開発

静的ファイルだけなのでビルド不要。

```bash
python3 -m http.server 8765
```

`http://127.0.0.1:8765/` を開く。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML/CSS/JS すべて） |
| `sw.js` | オフライン用のキャッシュ |
| `manifest.webmanifest` | ホーム画面に追加したときの設定 |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | アイコン |

## 制限

- 手書きの文字はほとんど読めない。印刷された文字が対象
- 日本語訳は出ない（端末内の OCR だけで完結させているため）
- 読み取りをまちがえることがある。そのための「なおす」モード
